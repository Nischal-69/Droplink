# DropLink client

React + TypeScript + Vite + Tailwind CSS frontend for DropLink.

See the **[root README](../README.md)** for architecture, local development,
WebRTC/signaling flows, production deployment, and security considerations.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # type-check + production bundle
npm run lint     # oxlint
```
